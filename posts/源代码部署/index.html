3.2 源代码部署（详细步骤）

3.2.1 适用场景

源代码部署把代码直接放在服务器目录，由系统的 Python 虚拟环境、systemd 和 Nginx 托管。

适合：

  • 单台小型服务器；
  • 项目依赖不复杂；
  • 希望直接看代码文件、进程和系统日志；
  • 学习 systemd、Nginx、venv 的完整原理。

3.2.8 配置 HTTPS 与上线验证

在宝塔站点设置中：

  1. 打开 SSL -> Let’s Encrypt。
  2. 选择域名并申请证书。
  3. 如果 80 端口验证失败，检查 DNS、A 记录、安全组、Nginx 80 监听和备案状态。
  4. 申请成功后开启强制 HTTPS。
  5. 浏览器访问 https://<域名>，确认锁标志和证书域名正确。

  • 首页加载无 404；
  • 子路由刷新不 404；
  • 登录、核心表单和 API 成功；
  • Network 中 /api 返回 2xx；
  • HTTPS 页面没有混合内容警告；
  • 移动端布局正常。

源代码部署的优点和代价：

  • 优点：结构直观、调试方便、资源开销小；
  • 代价：服务器环境需要自己维护，依赖版本容易漂移，迁移到新机器成本较高。
